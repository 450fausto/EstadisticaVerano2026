# Análisis de datos de ventas

Estudiaremos los datos de ventas de uno de los minoristas más grandes del mundo. El objetivo es identificar qué factores influyen en sus ingresos. ¿Pueden variables como la temperatura del aire y el costo del combustible afectar el desempeño de una empresa de esta magnitud, junto con el índice de precios al consumidor y los descuentos estacionales? Además, exploraremos cómo el aprendizaje automático (*Machine Learning*) puede ayudar a minimizar costos y aumentar el impacto económico.

## Descripción de las columnas

| Columna | Descripción |
|---------|-------------|
| **Store** | Número de la tienda. |
| **Date** | Fecha de inicio de la semana de ventas. |
| **Weekly_Sales** | Ventas semanales. |
| **Holiday_Flag** | Indicador de presencia o ausencia de un día festivo. |
| **Temperature** | Temperatura del aire en la región. |
| **Fuel_Price** | Costo del combustible en la región. |
| **CPI** | Índice de Precios al Consumidor (*Consumer Price Index*). |
| **Unemployment** | Tasa de desempleo. |
